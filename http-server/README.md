## Sources

| Source | Used for in this project |
| --- | --- |
| [Web Browser Engineering](https://browser.engineering/) | Understanding URLs, page loading, and the browser side of HTTP requests. |
| [Let's Build A Web Server, Part 1](https://ruslanspivak.com/lsbaws-part1/) | Following a minimal web server from socket setup through HTTP request and response handling. |

| [RFC 9112: HTTP/1.1](https://www.rfc-editor.org/info/rfc9112/) | Checking HTTP/1.1 message syntax, parsing, framing, and connection management. This reference covers HTTP, not TLS. |
